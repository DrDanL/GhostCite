👻 GhostCite

Reference verification tool — upload a PDF or Word document to check if cited references exist in Crossref.

⚠ Important: This tool checks whether references can be found in the Crossref database. A reference marked as "not found" does not mean it is fake or fabricated — many legitimate sources (books, reports, websites, preprints, and non-English publications) are not indexed by Crossref. Similarly, a "partial match" indicates that some but not all metadata aligns with a Crossref record, which may reflect formatting differences rather than errors. All results require human verification and should not be used as the sole basis for judging the integrity of a document's references.
